## Описание задачи

Необходимо реализовать физическое подключение к целевой базе данных PostgreSQL из Rust-приложения с помощью синхронного драйвера `postgres`. Задача слоя данных — извлечь метаданные таблицы (число строк, страниц) и статистику распределения конкретной колонки (MCV) для последующего расчёта селективности.

## Теоретическое обоснование (Такт 1)

Мы материализуем гомоморфизм между реляционными кортежами системных каталогов СУБД и структурами данных (Product Types) в Rust.

1. Данные об объёме конечной модели извлекаются из `pg_class` (атрибуты `reltuples` → мощность $N$, `relpages` → число страниц $B$).
2. Плотность распределения извлекается из `pg_stats` (атрибуты `null_frac`, `n_distinct`, `most_common_vals`, `most_common_freqs`).

## Шаги реализации (чек-лист)

- [ ] Инициализировать в `Cargo.toml` зависимости `postgres` и `serde_json`.
- [ ] Спроектировать структуру `Catalog` и связанные типы данных в Rust для хранения метаданных.
- [ ] Написать функцию инициализации клиента `Client::connect()` на основе переменной окружения `DATABASE_URL`.
- [ ] Сформировать SQL-запросы к `pg_class` и `pg_stats` для получения сырых метрик целевой таблицы.
- [ ] Реализовать маппинг (перевод) полученных строк базы данных в разработанные структуры Rust.
- [ ] Покрыть код базовым логированием для верификации успешного чтения статистики.

## Результат (Definition of Done)

Утилита успешно подключается к БД, запрашивает метаданные для конкретной таблицы (например, `flight`) и выводит в консоль структуры Rust, содержащие точные системные значения $N$, $B$ и массивы наиболее частых значений (MCV).
