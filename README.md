# pg-ray (Plan Generator & Relational Analysis sYstem)

`pg-ray` — это низкоуровневая утилита анализа и визуализации скрытого пространства
решений стоимостного планировщика (Cost-Based Optimizer) СУБД PostgreSQL.

## 🔬 Теоретический Фундамент

Утилита исследует базу данных как научно-компьютерный объект на стыке трех дисциплин:
1. **Теория Конечных Моделей (FMT)** — вычисление селективности предикатов первого порядка
   на конечных структурах отношений (мультимножествах).
2. **Теория Сложности Алгоритмов** — анализ точек перелома (Breakpoints) при столкновении
   линейной сложности $O(N)$ последовательного доступа и логарифмически-линейной
   сложности $O(\log N + M)$ случайного ввода-вывода (Random I/O).
3. **Теория Типов и Категорий** — аудит чистоты реляционных преобразований, включая
   анализ трехзначной логики (3VL) для `NULL` и морфизмов перехода между монадами
   мультимножеств (`Bag`) и упорядоченных списков (`List`).
## 🛠️ Функциональная Архитектура (MVP)

Программа работает непосредственно с живым инстансом PostgreSQL, извлекая системные метрики и данные планировщика:

1. **Поиск Точек Перелома (Cost Breakpoints)**
   Автоматическое сканирование графа стоимости. Путем контролируемого изменения
   параметров планировщика (`enable_seqscan`, `enable_indexscan`), утилита строит
   точную математическую кривую пересечения стоимостей физических операторов
   для заданного SQL-запроса.

2. **Анализ Локальности Данных (IO Density Analyzer)**
   Сопоставление кардинальности выборки (извлеченных кортежей) с реальным
   количеством затронутых страниц памяти в RAM (`Shared Buffers`) и на диске.
   Вычисление коэффициента плотности распределения данных.

3. **Аналитический Аудит Предикатов (3VL & Types Auditor)**
   Выявление скрытых логических аномалий в AST-дереве запроса: неявные приведения типов,
   блокирующие использование B-Tree индексов, и потенциальные логические тупики 
   трехзначной булевой логики из-за неопределенности `NULL`.

*Проект разрабатывается в академических и инженерно-исследовательских целях в рамках инициативы [SQL-Core].*
