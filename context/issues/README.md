# GitHub issues

Local snapshots of issues from `kshakirov/pg-ray` belong here. See
[`index.md`](index.md) for the current snapshot.

Suggested naming convention: `0001-short-title.md`. Each snapshot should contain
the issue number, state, labels, assignees, creation/update timestamps, source URL,
and body. An `index.md` may summarize all retrieved issues.

GitHub remains the source of truth. Snapshot files are imported records and should
not be edited as a substitute for updating the corresponding GitHub issue.
