# ADR 0001: Физическая топология и макро-граф воркфлоу СУБД

## Статус
Изучение / В процессе (In Progress)

## Контекст
Для проектирования утилиты `pg-ray` необходимо декомпозировать 
жизненный цикл запроса внутри целевой СУБД (PostgreSQL) и зафиксировать 
шаги его трансформации на верхнем уровне.

## Решение (Архитектурный Граф)
Принято решение исследовать и реализовать инструмент на основе 
последовательного обхода в ширину (BFS) следующих макро-узлов СУБД:
1. Транспортный слой (Модель Process-per-Connection)
2. Слой компиляции и переписывания термов (TRS)
3. Планировщик (Cost-Based Optimizer)
4. Движок выполнения (Конвейер итераторов Volcano)
5. Слой чтения (Алгоритмы сканирования и соединений)
6. Слой записи (Физика MVCC и WAL)
7. Слой управления памятью (Shared Buffers)
